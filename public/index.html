Um Missbrauch zu verhindern, erfolgt die Authentifizierung auf dlssdb.goover.dev verpflichtend über deinen Discord-Account. Beim ersten Login wird dein Account inklusive persönlichem dlss_live_... API Key sofort automatisch erstellt.

⚙️ Admin-Hinweis: Discord OAuth2 in Cloudflare einrichten (1 Minute)
  1. Öffne das Discord Developer Portal ↗ und klicke auf New Application.
  2. Klicke links auf OAuth2 und trage unter Redirects exakt diese URL ein:
    https://dlssdb.goover.dev/api/auth/discord/callback
  3. Kopiere im Discord Portal unter OAuth2 die CLIENT ID und das CLIENT SECRET (Reset Secret).
  4. Öffne dein Cloudflare Dashboard → Workers und Pages → dlss-manager-onlinedb → Einstellungen → Variablen und Geheimnisse und füge diese 2 Variablen hinzu:
    • DISCORD_CLIENT_ID
    • DISCORD_CLIENT_SECRET
